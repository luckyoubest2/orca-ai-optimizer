# orca-ai-optimizer（AI 对话优化）

虎鲸笔记（Orca Note）AI 对话体验优化插件。

> 项目状态：**已实现 v0.2.0** —— 手动新开对话、面板对话历史、对话管理与空对话自动清理。

## 已实现功能

### F0 手动拉起新的 AI 对话窗口（替换旧窗口）

块编辑器右侧工具条提供 AI 按钮（**普通文档与 AI 对话面板都会显示**）：

- **主按钮单击**：打开**这个面板上次唤起的 AI 对话**（按来源文档记录；校验存在且非空，
  失效自动新建）；
- **Shift + 主按钮**：在**侧边新面板**打开；
- **右键主按钮**：**立即新建**一个全新对话并在**当前面板替换**旧窗口
  （仅对 AI 对话面板生效，普通文档页无效；旧对话仍保留在文档中，可「返回」找回）；
- **时钟按钮**：拉起**对话管理窗口**并自动筛选**来源为当前面板文档**的对话记录。

### 新建 AI 对话（系统命令 / 顶栏可选）

- 注册系统命令 **`新建 AI 对话（替换当前）`**（命令面板可搜可绑定快捷键）：
  用新的 AI 对话面板**顶替当前 AI 对话面板**，仅对 AI 对话面板生效，普通面板无效；
- 顶栏「AI 对话」按钮**可选择是否显示**（设置项），点击打开对话管理窗口。

### F1 面板侧 AI 按钮：打开 / 查找该面板唤起的对话

- 插件维护「仓库 + 根块 → 对话历史」注册表（`orca.plugins.setData` 持久化），
  记录每个文档唤起过的对话（打开、新建、面板导航都会登记）；
- 时钟按钮把**对话管理窗口**按来源文档筛选后打开，相当于"该面板唤起过的全部对话"；
- 空对话清理后自动同步清除注册表中的失效条目。

### F2 AI 对话记录管理

- 顶栏新增 **AI 对话** 快捷按钮，也注册了 `AI 对话管理` 命令（命令面板可调用）：
  点击后弹出**管理窗口**，列出当前仓库全部 `aichat` 对话
  （标题 / 消息数 / 空对话标记 / 最后活跃 / 所属文档），带搜索；
- 点击行**预览**对话（不跳转），行内按钮支持**打开**（当前面板替换）、
  **重命名**（写 `_repr.cap`）、**删除**（可撤销路径 + 后端兜底）、**导出 Markdown**；
- 管理窗口提供**筛选**：按来源文档、消息数量（≥ N）、最后消息时间排序，
  以及全文搜索；
- **空对话自动清理**：识别 `msgs` 无 `role==="user"` 的空对话，白名单保护
  （不删当前展示的、最近打开过的、有引用/子块的），手动一键清理带预览与确认；
- 可选**自动清理**：应用启动后扫描，每天至多一次，按创建时长过滤，清理后通知报告。

## 安装与使用

1. 构建产物：`pnpm install && pnpm build`（产出 `dist/index.js`）；
2. 将本项目目录放入 Orca Note 插件目录（与 [Orca Pinner](https://github.com/luckyoubest2/Orca-pinner) 等同目录），
   在应用插件管理中启用；
3. 使用：任意文档编辑器右侧工具条找「新对话」按钮；顶栏 AI 按钮（或命令面板
   搜「AI 对话管理」）打开对话管理窗口。

## 设置项

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 在顶栏显示「AI 对话」按钮 | 开 | 关闭后仍可通过命令面板执行「AI 对话管理」 |
| 自动清理空对话 | 关 | 启动时扫描并清理空对话（有保护） |
| 空对话保留时长（小时） | 24 | 自动清理时跳过创建不足该时长的空对话 |
| 手动清理前先确认 | 开 | 对话管理窗口清理前弹确认框 |

## 兼容性说明

- 与 [Orca Pinner](https://github.com/luckyoubest2/Orca-pinner) 的冲突点已核实：
  pinner 全局包装 `orca.nav.goTo`，会把导航到 aichat 块的调用改为钉住浮窗打开；
- 本插件**面板内替换**动作手动复刻内置 `goTo` 的替换逻辑（改 `view/viewArgs` +
  维护返回历史），不触发任何 `goTo` 包装，保证「替换旧窗口」语义；
  侧边栏打开等其余路径仍走 `goTo`，显示位置交给 pinner。
