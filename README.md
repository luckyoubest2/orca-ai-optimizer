# orca-ai-optimizer（AI 对话优化）

虎鲸笔记（Orca Note）AI 对话体验优化插件。

> 项目状态：**占位**，当前仅包含可行性分析文档，尚未开工。

## 功能规划

### F1 面板侧 AI 按钮：打开 / 查找该面板唤起的对话

- 点击面板右侧工具条的 AI 按钮，默认打开**该面板上一次唤起的 AI 对话**；
- 从同一入口可列出、搜索**该面板唤起过的全部 AI 对话**，点选打开；
- 插件自行维护「面板（仓库 + 根块）→ 对话历史」注册表（`orca.plugins.setData` 持久化），
  记录"谁在哪个面板唤起过哪些对话"这一事实；
- 无历史或历史失效时回退为新建对话（保留内置行为）。

### F2 AI 对话记录管理

- 对话列表管理：查看当前仓库全部 `aichat` 对话（标题 / 消息数 / 最后活跃 / 所属文档），
  支持打开、重命名、删除、导出；
- **空对话自动清理**：自动识别并清理从未产生用户消息的对话块（`msgs` 无 `role==="user"`），
  带白名单保护（不删当前展示的、有引用的）与清理报告；
- 清理后同步维护 F1 的历史注册表，避免指向已删除的对话。

## 兼容性决策

- 与 [Orca Pinner](https://github.com/luckyoubest2/Orca-pinner) 的冲突点已核实
  （pinner 全局包装 `orca.nav.goTo`，会把导航到 aichat 块的调用改为钉住浮窗打开）；
- 当前决策：**顺其自然**——本插件只负责"找到 / 查找对话"，打开动作仍走 `goTo`，
  显示位置交给 pinner；兼容性细节后续再议。
