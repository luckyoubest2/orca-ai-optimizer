# orca-ai-optimizer（AI 对话优化）

虎鲸笔记（Orca Note）AI 对话体验优化插件。

> 项目状态：**已实现 v0.1.0** —— 手动新开 AI 对话窗口并替换旧窗口。

## 已实现功能

### F0 手动拉起新的 AI 对话窗口（替换旧窗口）

在块编辑器右侧工具条新增一个 **「新对话」** 按钮（AI 图标带橙色 `+` 角标）。

- **点按**：新建一个全新的 AI 对话块，并在**当前面板**打开——直接替换掉该面板
  正在显示的旧对话（旧对话内容仍保留在文档中，可用面板「返回」找回）；
- **Shift + 点按**：与内置 AI 按钮一致，在**侧边新面板**打开；
- **替换保护**：当前对话已有用户提问时，先弹出确认框再替换，避免误触丢失上下文；
- **上下文延续**：新对话沿用旧对话的 `ctx`（同一文档上下文），从新窗口继续提问；
- 未配置 AI 服务时提示并引导打开设置（与内置行为一致）。

#### 安装与使用

1. 构建产物：`pnpm install && pnpm build`（产出 `dist/index.js`）；
2. 将本项目目录放入 Orca Note 插件目录（与 [Orca Pinner](https://github.com/luckyoubest2/Orca-pinner) 等同目录），
   在应用插件管理中启用；
3. 打开任意文档，点击编辑器右侧工具条中的「新对话」按钮。

#### 设置项

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 替换有内容的对话前先确认 | 开 | 当前对话已有用户消息时先确认再替换 |
| 仅当当前面板显示 AI 对话时显示按钮 | 开 | 关闭后所有面板均显示按钮，随时手动新开对话 |

## 功能规划（后续）

### F1 面板侧 AI 按钮：打开 / 查找该面板唤起的对话

- 点击面板右侧工具条的 AI 按钮，默认打开**该面板上一次唤起的 AI 对话**；
- 从同一入口可列出、搜索**该面板唤起过的全部 AI 对话**，点选打开；
- 插件自行维护「面板（仓库 + 根块）→ 对话历史」注册表（`orca.plugins.setData` 持久化）；
- 无历史或历史失效时回退为新建对话。

### F2 AI 对话记录管理

- 对话列表管理：查看当前仓库全部 `aichat` 对话（标题 / 消息数 / 最后活跃 / 所属文档），
  支持打开、重命名、删除、导出；
- **空对话自动清理**：自动识别并清理从未产生用户消息的对话块（`msgs` 无 `role==="user"`），
  带白名单保护与清理报告。

## 兼容性说明

- 与 [Orca Pinner](https://github.com/luckyoubest2/Orca-pinner) 的冲突点已核实：
  pinner 全局包装 `orca.nav.goTo`，会把导航到 aichat 块的调用改为钉住浮窗打开；
- **F0 的处理**：新对话替换动作解析出 pinner 包装前的原始 `goTo`，在**当前面板内**替换，
  保证「替换旧窗口」语义；其余打开路径仍走 `goTo`，显示位置交给 pinner。
